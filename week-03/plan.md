# week-03 계획서 · 타자 치는 고양이 데스크톱 펫

## 만들 것
- 화면 오른쪽 아래에서 내가 키를 누를 때마다 키보드를 치는 고양이 펫
- 그림: `art/sheet.png` (2×2, 네 칸)
  - ① 왼쪽 위: 두 손 들기 → 아무것도 안 누를 때
  - ② 오른쪽 위 / ③ 왼쪽 아래: 한 손씩 누르기 → 키를 누를 때마다 ② ③ 번갈아
  - ④ 오른쪽 아래: 눈 감고 졸기 → 5초 동안 안 누르면
- 모양: 칸 선은 잘라 내고, 바깥 흰 배경만 투명하게. 고양이와 키보드만 보임 (고양이 몸 안쪽 흰색은 그대로)
- 자리와 크기: 오른쪽 아래, 작업 표시줄 바로 위. 가로 200픽셀. 끌어서 옮기기 없음
- 창: 언제나 맨 위에 떠 있음. 마우스는 펫을 통과해서 뒤 창을 누름
- 트레이 아이콘: 시계 옆에 작은 아이콘
  - 마우스를 올리면 누른 횟수만 보임 (예: `1234번`)
  - 오른쪽 클릭 → "끄기"
- 켜는 방법: `.exe` 더블클릭할 때만 (자동 시작 없음)

## 어디서 돌아가는지
- 내 컴퓨터: Windows 11
- 만들 때: Python 3.15 로 `week-03` 폴더 안에서 실행
- 다 만든 뒤: PyInstaller 로 묶은 `.exe` 하나 (Python 없어도 켜짐)

## 재료
| 재료 | 하는 일 |
| --- | --- |
| Python | 펫 프로그램 |
| PySide6-Essentials | 투명한 창, 맨 위에 띄우기, 마우스 통과, 트레이 아이콘 |
| pynput | 키를 눌렀는지 듣기 (횟수만 셈) |
| Pillow | 그림을 네 칸으로 자르고 배경 투명하게 하기 |
| PyInstaller | `.exe` 하나로 묶기 |

- 재료는 아직 설치되지 않았어요. 설치하기 전에 꼭 물어봐요.
- 설치는 `week-03/.venv` (이 폴더 전용 Python 공간) 안에만 해요. `.venv` 는 커밋하지 않아요.

## 단계

### 1단계 · 준비
- `week-03/.venv` 를 만들고, 허락을 받은 뒤 재료 네 가지를 설치해요.
- `.gitignore` 에 `.venv/`, `build/`, `__pycache__/`, `*.spec` 를 넣어요. (`dist/` 의 `.exe` 는 올리기로 했으니 빼지 않아요.)
- **확인할 것**
  - 재료 네 가지가 오류 없이 설치되는지. Python 3.15 가 새 버전이라 PySide6 가 아직 안 맞을 수 있어요. 안 되면 멈추고 어떻게 할지 물어봐요.
  - `git status` 에 `.venv` 가 보이지 않는지
- **커밋** `week-03: 1단계 준비 (.gitignore)`

### 2단계 · 그림 자르기
- `cut.py` 로 `sheet.png` 를 네 칸으로 자르고, 칸 선을 빼고, 바깥 흰 배경을 투명하게 해서 `art/frame1.png` ~ `art/frame4.png` 로 저장해요.
- 바깥에서부터 이어진 흰색만 지워서 고양이 몸 안쪽 흰색은 남겨요.
- **확인할 것**
  - 네 그림을 열어 보고, 칸 선이 안 남았는지, 고양이 몸이 투명해지지 않았는지
  - 네 그림의 크기와 고양이 위치가 같은지 (바뀔 때 고양이가 흔들리지 않게)
- **커밋** `week-03: 2단계 그림 네 칸으로 자르기`

### 3단계 · 화면에 띄우기
- `pet.py` 로 투명한 창에 ① 그림을 가로 200픽셀로 띄워요.
- 오른쪽 아래, 작업 표시줄 바로 위에 두고, 언제나 맨 위에, 마우스는 통과하게 해요.
- **확인할 것**
  - 흰 네모 없이 고양이와 키보드만 보이는지
  - 다른 창을 열어도 펫이 위에 있는지
  - 펫 뒤에 있는 창을 클릭할 수 있는지
  - 작업 표시줄을 가리지 않는지
- **커밋** `week-03: 3단계 투명한 창에 펫 띄우기`

### 4단계 · 트레이 아이콘과 끄기
- 시계 옆에 트레이 아이콘을 만들고 오른쪽 클릭 메뉴에 "끄기"를 넣어요.
- **확인할 것**
  - 아이콘이 보이는지
  - "끄기"를 누르면 펫과 아이콘이 모두 사라지고 프로그램이 끝나는지 (작업 관리자에 남지 않는지)
- **커밋** `week-03: 4단계 트레이 아이콘과 끄기`

### 5단계 · 타자에 맞춰 움직이기
- pynput 으로 키를 누를 때마다 ② ③ 을 번갈아 보여 줘요. 잠깐 뒤 ① 로 돌아가요.
- 5초 동안 안 누르면 ④ 로 졸아요. 다시 누르면 깨어나요.
- 누른 횟수를 세서 트레이 아이콘에 `1234번` 처럼 보여 줘요.
- **확인할 것**
  - 메모장에 글을 쳐 보면 손이 번갈아 움직이는지
  - 5초 기다리면 졸고, 키를 누르면 깨는지
  - 트레이 아이콘에 마우스를 올리면 숫자만 늘어나는지
  - 코드 어디에도 어떤 키를 눌렀는지 저장하거나 보내는 부분이 없는지
- **커밋** `week-03: 5단계 타자에 맞춰 움직이고 횟수 세기`

### 6단계 · .exe 로 묶기
- PyInstaller 로 그림까지 넣은 `.exe` 하나를 `dist/` 에 만들어요.
- **확인할 것**
  - `.exe` 를 더블클릭하면 3~5단계가 그대로 되는지
  - 검은 명령어 창이 같이 뜨지 않는지
  - `.exe` 크기. GitHub 는 50MB 가 넘으면 경고하고 100MB 가 넘으면 올라가지 않아요. 100MB 가 넘으면 멈추고 어떻게 할지 물어봐요.
- **커밋** `week-03: 6단계 exe 로 묶기` (`.exe` 포함)

## 하지 말 것
- 어떤 키를 눌렀는지 저장하거나 보내지 않기. 횟수만 세고, 그 숫자도 파일에 저장하지 않기
- 컴퓨터를 켤 때 자동으로 켜지게 하지 않기 (작업실 밖을 건드림)
- `week-03` 폴더 밖에 파일을 만들거나 고치지 않기
- 허락 없이 재료 설치하지 않기
- 한 단계의 "확인할 것"을 다 보기 전에 다음 단계로 넘어가지 않기
- 내가 하자고 하기 전에 GitHub 에 올리지(푸시) 않기
- 정한 것 밖의 기능(끌어서 옮기기, 소리, 설정 창 등)을 마음대로 넣지 않기
